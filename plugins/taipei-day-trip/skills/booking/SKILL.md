# 台北一日遊預定流程

使用者想要預定台北市的景點導覽行程時，依照下面的步驟進行。

## 步驟

1. 請使用者輸入想去的景點關鍵字或捷運站名，例如「北投」或「中正紀念堂」。

2. 使用「搜尋台北市景點」工具搜尋，參數 keyword 填使用者給的關鍵字。

3. 把搜尋結果列出來給使用者看，每一筆至少要顯示景點編號和景點名稱。

4. 請使用者用自然語言回覆想預定的景點編號、日期和時段。

5. 把使用者的回覆轉換成系統需要的格式：
   - date 必須是 `YYYY-MM-DD`，例如 `2026-09-25`
   - time 只能是 `morning` 或 `afternoon`
   - price 由時段決定，morning 是 2000，afternoon 是 2500
   - attraction_id 是步驟三列出的景點編號

6. 使用「預定景點導覽行程」工具建立預定，四個參數都要填。

7. 預定成功後，把工具回傳訊息裡的付款頁面連結顯示給使用者，請他前往完成付款。

## 注意事項

- 時段只有上午和下午兩種，使用者說其他時間就告訴他只提供這兩個時段。
- 價格是固定的，不接受使用者指定金額。
- 搜尋工具不需要驗證身分，預定工具需要有效的存取金鑰。
- 如果工具回傳 `{"error": true}`，代表資料格式有問題或金鑰無效，請告訴使用者並重新確認輸入。
